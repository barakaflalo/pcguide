# מדריך המחשב · AppNest 3.0.0

מדריך לימודי בעברית ובאנגלית לפקודות Windows, כלי מערכת ופתרון תקלות. מבוסס על האפליקציה של Barak Aflalo. המדריך פועל בדפדפן ומציג הוראות ופקודות להעתקה; הוא **אינו מפעיל אותן במחשב**.

## פתיחה והעלאה ל-GitHub Pages

הקובץ `PC-Guide-AppNest-3-GitHub-Pages.zip` הוא חבילת אתר. אין קובץ התקנה או תוכנית שצריך להריץ.

1. באתר הקיים, ייצאו גיבוי דרך הגדרות לפני החלפת הגרסה.
2. חלצו את ה-ZIP.
3. העלו את **כל הקבצים והתיקיות שחולצו**, כולל תיקיית `assets` וכל תכולתה וקובץ `.nojekyll`, לתיקיית הפרסום שבה נמצא `index.html`. החליפו קבצים בעלי אותם שמות. העלאת ה-ZIP לבדו או רק `index.html` אינה מספיקה.
4. שמרו את השינויים במאגר והמתינו להשלמת פרסום GitHub Pages.
5. פתחו את כתובת המדריך ובדקו שמוצגת גרסה **3.0.0**. אם הגרסה הישנה עדיין מוצגת, סגרו את לשוניות המדריך ופתחו שוב לאחר סיום הפרסום.

אם GitHub Pages כבר מוגדר לאותה תיקייה, אפשר להמשיך להשתמש בהגדרה הקיימת. במאגר חדש יש לבחור מקור פרסום שכולל את `index.html` בראש תיקיית האתר.

אפשר לפתוח את `index.html` ישירות בדפדפן לתצוגה מקומית. תמיכת האופליין באמצעות Service Worker מחייבת אתר שמוגש ב-HTTPS או סביבת localhost; היא אינה פועלת מכתובת `file://`.

## מה כלול

- **156 נושאים**, עם חיפוש בעברית, באנגלית ובתחביר הפקודה, מועדפים וסינון לפי סוג כלי, סיכון והתאמה לפרופיל.
- **68 כרטיסי CMD ו-PowerShell** עם הכנות, תוצאה צפויה, דוגמת פלט ופירושה, שגיאות אפשריות והנחיות עצירה או ביטול. הפלטים מסומנים כדוגמאות להמחשה ואינם תוצאות מהמחשב שלכם.
- **12 מסלולי פתרון תקלות ובהם 102 צמתים**. בוחרים תשובה לפי מה שרואים, והמסלול ממשיך לענף המתאים. התשובות וההתקדמות נשמרות בדפדפן.
- **6 תרחישי תרגול בני שלושה שלבים — 18 שלבים בסך הכול**, לצד **6 שיעורים קצרים**, עם משוב והסבר לתשובות.
- **9 תרשימים סכמטיים** ו-**4 צילומי מסך מקוריים של Microsoft ל-Windows 10/11**. הצילומים נשארו באנגלית המקורית ומלווים בהסברים וסימונים בעברית ובאנגלית. הם דוגמאות לממשק, ולא צילום של המחשב שלכם.
- סימון סיכון והצגת הכנות לפני העתקה. בכרטיסים מתאימים נדרש לסמן שקראתם את ההנחיות לפני הפעלת כפתור ההעתקה.

נוספו כלים שימושיים לחיפוש קבצים וטקסט, קריאת הרשאות, השוואת טביעות קבצים, תצוגה מקדימה להעתקה ולגיבוי, בדיקת USB ו-Bluetooth ומלאי דרייברים ודיסקים.

## פרופיל המחשב והתאמה

בפרופיל אפשר לבחור גרסת Windows, מהדורה, מספר Build, ארכיטקטורה לרבות ARM64, גרסת PowerShell, זמינות מודולים ו-winget. שפת הממשק ושפת Windows הן בחירות נפרדות.

המידע מוזן **ידנית**; האתר אינו מזהה את תצורת המחשב. אפשר להשאיר פרטים כ״לא ידוע״. מצב כזה אינו מוצג כהבטחת התאמה: דרישות שלא אומתו עדיין מצריכות בדיקה. כלים מסוימים תלויים גם בעדכון מסוים, בחומרה, במודול מותקן או במדיניות הארגון.

פרופילים קודמים מגרסאות 1 ו-2 עוברים התאמה למבנה החדש. סימוני רשימת הבדיקות הישנה אינם הופכים לתשובות במסלולים המסתעפים; יש לבחור תשובות במסלול החדש.

## שמירה, גיבוי ואופליין

העדפות, מועדפים והתקדמות נשמרים בדפדפן. ייצוא וייבוא הגיבוי מאפשרים להעביר אותם לדפדפן או למכשיר אחר, עם בדיקת תקינות לפני השחזור. **מפתחות API אינם נכללים בקובץ הגיבוי**.

לאחר טעינה ראשונה מוצלחת דרך אתר מתאים והשלמת שמירת המטמון, התוכן המובנה והתמונות מיועדים לשימוש גם ללא רשת. קישורים חיצוניים ושירותי AI מרוחקים דורשים חיבור. המטמון מוגבל לתיקיית המדריך.

## בדיקות וגבולות הכיסוי

עברו **62 בדיקות אוטומטיות**: 41 בדיקות רגרסיה ושילוב ו-21 בדיקות מצב וגרף המסלולים.

נבדקו בדפדפן: עברית ו-RTL, אנגלית ו-LTR, בחירת ענפים ושמירתם, משוב בתרגולים, פרופילי Home ו-Pro, דחיית Build לא תקין, ARM64, טעינת התמונות ובדיקת מבנה העמוד ברוחב 390 פיקסלים ללא גלישה אופקית.

בדיקת אופליין עברה: לאחר טעינה מלאה כובה שרת הבדיקה, והמדריך נטען מחדש מהמטמון, כולל גלריית ההמחשות וצילום Windows Backup שלא נפתח קודם.

זהו קטלוג שימושי, **לא רשימה ממצה של כל פקודות Windows**. המסלולים החדשים מיועדים ל-Windows 10/11. לא אומתה כל פקודה בכל מהדורה היסטורית, ושמות תפריטים וזמינות כלים עשויים להשתנות בין עדכונים ומכשירים.

במהלך הבדיקות לא הופעלו פקודות מערכת ההפעלה המתוארות במדריך, לא בוצעו קריאות AI אמיתיות, והאתר לא פורסם לחשבון GitHub של המשתמש. הסימונים והמסלולים מסייעים ללמידה; הם אינם אבחון אוטומטי של המחשב.

## מקורות וקובצי החבילה

קישורים למקורות הרשמיים מופיעים בכרטיסים, במסלולים ובחומרי הלמידה. מקורות צילומי המסך ותיעוד מקורם נמצאים ב-[assets/windows-guides/sources.json](assets/windows-guides/sources.json).

יש לפרסם את כל קובצי ה-HTML, JavaScript, CSS, האייקונים, `manifest.json`, `sw.js` ותיקיית הנכסים יחד. בשחרור עתידי שמשנה קבצים יש לעדכן גם את מזהה המטמון ואת רשימת הנכסים ב-`sw.js`.
